10.2А · Уроки 65–70

Как из числа
получить угол?

Одному значению синуса могут соответствовать разные углы. Чтобы получить обратную функцию, оставляем одну ветвь, на которой каждое допустимое значение встречается один раз.

График и его отражение

Синий — прямая функция · золотой — обратная · пунктир — y = x

Два разных ограничения

У arcsin и arccos вход a должен быть от −1 до 1. Значение обратной функции — угол из выбранной ветви. Например, sin(5π/6) = 1/2, но arcsin(1/2) = π/6, потому что 5π/6 лежит вне [−π/2; π/2]. Для arctg и arcctg входом может быть любое действительное число.

arcsin a + arccos a = π/2 при |a| ≤ 1. В принятой здесь ветви arcctg a = π/2 − arctg a.

Уроки 71–84

Почему появляется +2πk?

Один полный оборот возвращает точку на окружности туда же. У sin и cos повторение через 2π. У tg и ctg отношение координат повторяется уже через π, когда обе координаты меняют знак.

k ∈ ℤ. Для sin и cos сначала найдите все точки за один оборот. Затем прибавьте к каждой целое число периодов. Если точки совпадают, оставьте одну серию.

Формулы и множители

sin 2x = sin x → sin x(2cos x − 1) = 0. Решаем sin x = 0 и cos x = 1/2 по отдельности.

Замена переменной

Для 2sin²x − 3sin x + 1 = 0 положим t = sin x. Корни t = 1 и t = 1/2 допустимы. Значения t вне [−1; 1] отбрасываем.

Однородные уравнения

В sin x − cos x = 0 сначала проверяем cos x = 0, затем делим на cos x и получаем tg x = 1. Для sin²x − 3sin x cos x + 2cos²x = 0 после проверки cos x = 0 делим на cos²x и получаем t² − 3t + 2 = 0, где t = tg x.

Уроки 85–88

Какие углы подходят?

Передвиньте уровень a. Синие участки на оси показывают углы, где выполняется выбранный знак. Пустая точка обозначает исключённую границу, закрашенная — включённую.

Например, sin x ≥ 1/2 даёт [π/6 + 2πk; 5π/6 + 2πk]. При строгом знаке концы исключаются. Точки разрыва tg и ctg всегда исключаются.

Формулы приведения

При сдвиге на π/2 или 3π/2 название меняется: sin ↔ cos, tg ↔ ctg. При π или 2π название сохраняется. Знак берём по четверти исходного угла, считая α острым.

sin(π−α) = sin α
cos(π−α) = −cos α
sin(π/2+α) = cos α
cos(π/2+α) = −sin α
tg(π/2−α) = ctg α
ctg(π/2+α) = −tg α

Основные тождества

sin²x + cos²x = 1
tg x = sin x / cos x, cos x ≠ 0
ctg x = cos x / sin x, sin x ≠ 0
1 + tg²x = 1/cos²x
1 + ctg²x = 1/sin²x

sin, tg, ctg нечётные на своих областях определения, cos чётный.

Сумма, разность и двойной угол

sin(a±b) = sin a cos b ± cos a sin b
cos(a±b) = cos a cos b ∓ sin a sin b
tg(a±b) = (tg a ± tg b)/(1 ∓ tg a tg b), когда обе части определены

sin 2x = 2sin x cos x
cos 2x = cos²x − sin²x = 2cos²x − 1
sin²x = (1 − cos 2x)/2
cos²x = (1 + cos 2x)/2

Сумма в произведение

sin a + sin b = 2sin((a+b)/2)cos((a−b)/2)
sin a − sin b = 2cos((a+b)/2)sin((a−b)/2)
cos a + cos b = 2cos((a+b)/2)cos((a−b)/2)
cos a − cos b = −2sin((a+b)/2)sin((a−b)/2)
